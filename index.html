安装到电脑客户端

下载下方的“桌宠清单”和“透明图集”，保持文件名为 pet.json 与 spritesheet.png，放入同一个文件夹：

Windows：%USERPROFILE%\.codex\pets\gpt-dragon-girl\
macOS / Linux：~/.codex/pets/gpt-dragon-girl/

如果设置了 CODEX_HOME，请使用对应目录。重新打开客户端，在“设置 → Pets”选择“GPT小龙女”，输入 /pet 显示。

也可下载完整仓库或 Release 安装包，在解压后的目录运行：Windows 使用 py -3 scripts/install.py，macOS / Linux 使用 python3 scripts/install.py。脚本需要 Python 3.10+。
